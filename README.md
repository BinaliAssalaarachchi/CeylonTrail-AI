# CeylonTrail AI

CeylonTrail AI is an intelligent Sri Lankan tourism planning and
coordination platform developed for the SE3090 Software Engineering
Frameworks Assignment 1.

## Technology Stack

- ASP.NET Core Web API
- PostgreSQL
- Entity Framework Core
- React
- Flutter
- Agentic AI
- GitHub Actions

## Applications

### Flutter Mobile Application
Tourist-facing application for:
- destination discovery
- trip creation
- AI itinerary planning
- bookings
- maps and travel information

### React Web Application
Provider, coordinator and administrator portal for:
- attraction management
- booking management
- AI workflow monitoring
- human approvals
- reporting and administration

## Primary Components

1. Trip & AI Itinerary Planning
2. Attractions & Experiences
3. Booking & Reservation Management
4. Travel Validation & Tourism Operations

## Agentic AI

The system will use four specialized agents:

1. Planner Agent
2. Destination Agent
3. Booking / Action Agent
4. Validation & Travel Intelligence Agent
